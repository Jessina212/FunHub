#### Video Demo: https://youtu.be/5evmX99elEs
#### Description:
![FunHub Logo](<FunHub.png>)
This project consists of games to lighten up and refresh the user's mood. It was a very fun project to create.
It consists of 2 games so far (keeping it open to extend the functionality in the future!), one of which- 'NumGuesser' is inspired by a viral game going around TikTok, Youtube Shorts and Instagram Reels, wherein two people choose their 4-digit numbers and try to guess each other's numbers. Here it has been implemented as a one player game- in the form of the computer and a user.
The other game- 'AnimalTalk' is a fun idea I came up with. The user inputs whichever character they want to be (among the ones available in the cowsay library), and what they want that character to say, and that is printed onto the screen.
It was created keeping in mind how much getting relaxed and lightening our moods is important to keep grinding in this race called life.

#### Functionality
Allow me to introduce how the project was made -
1. Firstly the Main Menu:
a. The user is greeted and then a menu for the games is displayed, for the user to choose games from.
b. Another menu is displayed when the user is finished with any of the games- which asks the user to play again, play another game or quit.

2. NumGuesser
a. A 4-digit number is randomly chosen by the computer at the start of the game.
b. Has a time limit (120s) and a number of turns limit (20), depending on whichever is reached first, the user loses and the number is displayed.
c. When the user wins, certain statistics- number of turns and the time taken by the user are printed.

3. AnimalTalk- A fun game implemented using the cowsay library (it seems like a fun animation library, so had some fun with it myself!), wherein the user chooses their character and dialogue and that itself is printed onto the screen.
